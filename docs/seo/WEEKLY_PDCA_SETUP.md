# ToolBoxJP 週次 SEO PDCA — 初回設定手順

毎週 日曜24時（月曜0:00 JST）に、Claude がクラウド上で次を自動実行します。PC の電源・スリープとは無関係に動きます。

1. Search Console のデータ取得（`npm run gsc:fetch`）
2. 分析・反省（前週比・前の28日比・過去の施策の効果判定）
3. 市場・制度のリサーチ
4. 改善の実装（別ブランチ・テスト・ビルドまで）
5. プルリクエスト作成 → **Gmail で承認依頼メール**を送信
6. あなたが GitHub でマージ（承認）→ Vercel が本番公開

承認（マージ）されない限り、本番には何も公開されません。

---

## あなたの作業（初回のみ・約10〜15分）

### ① サービスアカウントを作る（Google Cloud）
1. https://console.cloud.google.com/ を開き、プロジェクトを選ぶ（なければ「新しいプロジェクト」→ 名前は例: `toolboxjp-seo`）
2. 「API とサービス」→「ライブラリ」→ **Google Search Console API** を検索して「有効にする」
3. 「IAM と管理」→「サービスアカウント」→「サービスアカウントを作成」
   - 名前: `gsc-reader`（ロールの付与は不要。スキップして完了）
4. 作成したサービスアカウントを開く →「キー」→「キーを追加」→「新しい鍵を作成」→ **JSON** → ダウンロード
   - この JSON ファイルはパスワードと同じ扱いです。メール・チャット・リポジトリに貼らないでください。
5. サービスアカウントのメールアドレス（`gsc-reader@…iam.gserviceaccount.com`）を控える

### ② Search Console に閲覧者として追加
1. https://search.google.com/search-console → toolboxjp.com のプロパティ
2. 「設定」→「ユーザーと権限」→「ユーザーを追加」
3. ①-5 のメールアドレスを入力、権限は **「制限付き」**（閲覧のみ）

### ③ 鍵をクラウド環境に登録
claude.ai の Claude Code（クラウド）の「環境」設定で、環境変数（秘密情報）として登録します。
- `GSC_SA_KEY_B64` … 鍵 JSON を base64 にした値（`base64 -i 鍵ファイル | tr -d '\n'` で作れる）
- `GSC_SITE_URL` … `https://www.toolboxjp.com/`（URL プレフィックスのプロパティ。省略時も既定でこの値）

> 鍵の値を Claude に送る必要はありません。登録後に「登録した」とだけ伝えてください。

### ④ Gmail コネクタを接続
Claude の画面に表示された Gmail の「Connect」から接続します（承認依頼メールの送信に使います）。

### ⑤ （任意）レポート保管用の非公開リポジトリ
web-tools は**公開リポジトリ**のため、Search Console の数値・週次レポートはそこに保存しません。
過去の施策と効果を毎週引き継ぐため、非公開リポジトリ（例: `toolboxjp-seo-ops`）を1つ用意することを推奨します。

## 毎週あなたに届くメール（月曜朝）
- 件名: `[ToolBoxJP 週次] 承認のお願い（YYYY-MM-DD）`
- 本文: 今週の数字（前週比）／良かった点・反省点／市場の動き／実装した改善（根拠 URL 付き）／プルリクエストのリンク
- 承認: リンク先の GitHub でマージ（スマホの GitHub アプリでも可）。見送る場合は何もしなくて OK

## 自動公開しない（必ず承認を求める）もの
すべての変更は承認制です。特に次は根拠（一次資料 URL）を必ず添えます。
- 税・社会保険・補助金など制度にかかわる数値
- 新規ツール・ページの追加、既存 UI の変更
- 料金・広告・アフィリエイトにかかわる変更
